# Description

Commonly used python utils.

# Depends on `uv` package manager

# Installation

Include in uv `pyproject.toml` in `dependecies` and `[tool.uv.sources]`:

```
[project]
...
dependencies = [
    "py-utils",
]

[tool.uv.sources]
py-utils = { git = "https://github.com/dreu007/py-utils.git"}
```
